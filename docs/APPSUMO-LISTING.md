# Bridgistic — AppSumo listing brief

## One-line positioning

Give WordPress a safe AI control plane: connect Claude, ChatGPT, Codex, Gemini, Cursor, and other MCP clients through scoped keys, approvals, snapshots, and an audit trail.

## What customers receive today

- Free WordPress plugin with local MCP connection support.
- HMAC-signed connection keys with least-privilege scopes.
- Approval queue for risky writes and destructive actions.
- Pre-change snapshots with restore support where the operation supports it.
- Audit history and CSV export from the dashboard.
- Site context memory scan for `llms.txt`, `llms-full.txt`, `sitemap.xml`, and WordPress site metadata.
- Built-in playbooks and WP-Cron schedules for repeatable site operations.
- WordPress content, media, users, plugins, options, files, database, and WooCommerce tools behind the same policy layer.
- Skills marketplace access for eligible Pro customers.
- Updates and license verification through the WPistic license service.

## Customer promise

Bridgistic helps a customer give an AI assistant enough access to work on WordPress without handing over the WordPress administrator password. Customers start read-only, widen scopes deliberately, and can require approval before changes.

## Important scope notes

- The owner platform console at `admin.bridgistic.app` is not a customer feature and is never included in customer access.
- The customer dashboard is at `dashboard.bridgistic.app`.
- The public skills directory is at `marketplace.bridgistic.app/`.
- Remote MCP is available at `https://mcp.bridgistic.app/mcp` where the customer chooses the cloud connector; local MCP remains the recommended default when supported.
- Cloud Agent credits, agency team permissions, and white-label features are separate roadmap items, not promises in this offer.
