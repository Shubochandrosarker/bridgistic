# Bridgistic OpenAI directory submission

This directory is the source of truth for the portable Agent Plugin ZIP. It
contains no credentials and points at the stable hosted MCP origin:

`https://mcp.bridgistic.app/mcp`

## Current state

- Package metadata: prepared for version 1.5.15.
- OAuth: DCR is declared; the hosted server exposes OAuth discovery and PKCE.
- Default connection scope: `site:read` and `posts:read`.
- Tool security metadata: emitted from the shared Bridgistic contract catalogue.
- Public website, support, privacy and terms URLs: reachable during the current audit.
- Demo recording URL: not supplied yet.
- Reviewer credentials and dedicated demo tenant: not supplied yet.
- OpenAI organization/developer verification: must be completed in the portal.
- Domain challenge: requires the token generated by the OpenAI portal, stored as
  the Cloudflare Worker secret `OPENAI_APPS_CHALLENGE`, then verified at
  `https://mcp.bridgistic.app/.well-known/openai-apps-challenge`.

## Before upload

1. Create a dedicated reviewer WordPress site with harmless sample pages and media.
2. Create a reviewer key with only `site:read` and `posts:read` for the five
   positive cases and negative-scope checks.
3. Run all five positive and three negative cases against that tenant.
4. Record a reviewer-accessible walkthrough without showing credentials.
5. Add the recording URL to `extensions.com.openai.review.demo_recording_url`.
6. Upload the ZIP through the OpenAI Plugins dashboard, complete the domain
   challenge, connect and scan the MCP server, and resolve findings.
7. Enter reviewer credentials only in the private Review details form.

The package must not contain reviewer passwords, OAuth client secrets, access
tokens, or private URLs.
