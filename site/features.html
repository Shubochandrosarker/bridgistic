Shipping in the free plugin

Shipping

Scoped connection keys

Each AI client gets its own key. Start with Read-only. Content Manager, Safe Admin and Developer Mode are wider presets. The WordPress administrator password is not the credential.

Create a key · Security model

Shipping

Signed requests

Local requests are HMAC-signed. The plugin checks the signature, the timestamp and the nonce before a tool runs.

Security notes

Shipping

Approvals

A key can require a person to allow writes. Pending actions sit in Bridgistic, then Approvals.

How approval works

Shipping

Manual playbooks

A playbook is an ordered list of bridge steps. You run it from WordPress or from the MCP tool. It does not recurse into other playbooks.

Playbooks

Shipping

WooCommerce tools

Commerce tools use the same key, scopes and approval rules. They are not a separate plan.

Multi-site connections

A local client can keep several sites in one connections file and call them by alias.

Connect a client

Shipping

Health check and setup export

Health Check looks at REST, permalinks and signing. Export Package builds a setup zip for a client. That export is not an audit-log download.

Scheduled playbooks

Shipping

Up to 3 schedules

The free plugin allows 3 enabled schedules. The cap is enforced in code before a schedule is created or enabled. The message on the REST API says 3 enabled schedules are included in the free plugin.

With a license

Unlimited scheduled playbooks

The free cap is 3 enabled schedules. When the license link reports active, trialing, or grace, that cap is skipped. The key is the one emailed after checkout, checked by the plugin and the dashboard against api.wpistic.com.

Snapshots

Shipping

Snapshots and restore

Destructive writes can store a snapshot first. You can also take a manual snapshot of posts and post meta, and restore one. The free screen keeps up to 50 snapshots.

With a license

Advanced snapshots

The free screen keeps up to 50 snapshots. A live license lifts that cap. Retention policies and rollback analytics are not a separate screen.

Audit log

Shipping

Audit log, 90 days

Requests are logged with the key, action, status and time. Secrets are not written into the log. Rows older than 90 days are pruned.

With a license

Audit log export

The on-screen log stays free for 90 days. A live license opens GET /wp-json/bridgistic/v1/audit/export for the same rows. The Export Package screen is still a setup zip, not the log.
