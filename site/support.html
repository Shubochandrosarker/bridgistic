Send a useful support request

Include enough context for one reply to move the issue forward:

  1. The account email used for Bridgistic or the AppSumo order email.
  2. Your site domain, WordPress version, PHP version and Bridgistic plugin version.
  3. The AI client you used and whether the key is Read-only or a wider scope.
  4. The exact error message, the action that failed and the time it happened.
  5. A screenshot or short screen recording with passwords, key secrets and private customer data removed.

Never send: a WordPress administrator password, connection-key secret, Stripe or Paddle secret, or a database export.

Before you email

  1. Confirm the plugin is active and the site uses HTTPS.
  2. Open Bridgistic → Health Check and fix any red result.
  3. Create a fresh Read-only key and copy its secret once.
  4. Run a site-info read from the client, then check Bridgistic → Logs.
  5. Revoke a key if it was exposed, then create a replacement.

Local mode is the recommended default. Bridgistic Cloud is a public beta; do not use it for high-risk production access until your review is complete.

Billing and refunds

Stripe is the default checkout for Bridgistic. WordPressistic LLC is the seller for Stripe transactions. Paddle remains an optional checkout provider.

Every purchase has a 7-day refund guarantee. A full refund revokes the associated license. After 7 days, discretionary refunds are not available, while applicable-law, duplicate, unauthorized, provider-error and valid chargeback cases remain reviewable.

For a billing request, email support@wpistic.com from the purchase email when possible. Do not send payment details by email.

Security reports

Send suspected security vulnerabilities to support@wpistic.com with “Security report” in the subject. Include the affected component, reproduction steps and impact. Keep the report private until we acknowledge it.

Bridgistic does not require your WordPress administrator password. Requests use scoped keys, signatures, approvals and an audit trail. The security documentation describes the current model and its limits.

Common questions

Where should I start?

Read the setup docs, install Bridgistic, create a Read-only key and run a site-info check before widening permissions.

Do I need the dashboard to use Bridgistic?

No. The free local bridge can run without an account. The dashboard is useful for connected-site status, license activation, logs and account billing.

What should I include in a support request?

Include the account or AppSumo order email, site domain, versions, client, exact error and reproduction steps. Never send a key secret or WordPress administrator password.

How do billing and refunds work?

Stripe is the default checkout and Paddle remains optional. Purchases have a 7-day refund guarantee. Full refunds revoke the license. See the Refund Policy.

Where should I report a public bug?

Remove private information, then use GitHub Issues. Use email for account, billing or security matters.
