Security questions

Report a concern privately by email. Never post credentials or site details in a public issue. See Security reports.

Send a useful support request

Include enough detail for one reply to move the issue forward:

  • The account email you use for Bridgistic, or your AppSumo order email.
  • Your site domain, WordPress version, PHP version and Bridgistic plugin version.
  • The AI client you used and the key’s scope (for example Read-only).
  • The exact error message, what you were doing and when it happened.
  • A screenshot or short screen recording with passwords, key secrets and customer data removed.

Never send a WordPress administrator password, a connection-key secret, a payment card number or a database export.

Before you email

  1. Check that the plugin is active and the site uses HTTPS.
  2. Open Bridgistic → Health Check in WP Admin and fix any red result.
  3. Create a fresh Read-only key and copy its secret once.
  4. Run a site-info read from your AI client, then check Bridgistic → Logs.
  5. If requests stop with bridgistic_free_limit_reached, the site has used this month’s free allowance. See Free and Pro limits.
  6. If a key was exposed, revoke it and create a replacement.

Local mode is the recommended default. Bridgistic Cloud is a public beta and has not had an independent security review yet.

AppSumo redemption

  1. Open bridgistic.app/redeem.
  2. Create a Bridgistic account, or sign in if you already have one. Use the email you want the license tied to.
  3. Enter your AppSumo code and submit. Your Bridgistic license key (it starts with BRG-) appears on screen. Copy it.
  4. In WP Admin, open Bridgistic → Premium Features, paste the key and activate it.

The number of sites depends on the AppSumo tier: Tier 1 covers 1 site, Tier 2 covers 3 sites and Tier 3 covers 5 sites. If a code is rejected or already used, email support@bridgistic.app with your AppSumo order email. Do not include the code in the subject line.

Billing and refunds

Checkout is handled by Stripe at pay.bridgistic.app. WordPressistic LLC is the seller, and taxes are shown at checkout.

Every purchase has a 7-day refund guarantee. A full refund revokes the license. Read the refund policy and how purchases work.

For billing questions, email support@bridgistic.app from your purchase email if you can. Never send card details by email.

Security reports

Send suspected vulnerabilities to support@bridgistic.app with “Security report” in the subject. Include the affected component, steps to reproduce and the impact. Please keep the report private until we confirm it.

Bridgistic never needs your WordPress administrator password. Requests use scoped keys, HMAC signatures, approvals and an audit trail.

Common questions

Where should I start?

Read the quickstart, install Bridgistic, create a Read-only key and run a site-info check before you give the key more scopes.

Do I need an account to use Bridgistic?

No. The free local bridge works without an account. The dashboard shows connected-site status, licenses and logs.

What happens when the free allowance runs out?

AI clients get a clear message with the reset date and the upgrade link, and administrators see a notice in WP Admin. The site itself keeps working, and the allowance resets on the 1st of the next month (UTC).

How do I move my license to another site?

Deactivate it under Bridgistic → Premium Features on the old site, or delete the plugin there, which releases the seat. Then activate it on the new site.

How do refunds work?

Purchases have a 7-day refund guarantee, and a full refund revokes the license. See the refund policy.

Where do I report a public bug?

Remove private information first, then open an issue on GitHub. Use email for account, billing or security matters.
